Le navigateur ne peut pas accéder au port USB

La mise en service depuis le navigateur utilise l'API Web Serial. Il faut :

  • Chrome, Edge ou Opera sur ordinateur (pas Firefox ni Safari) ;
  • une page servie en HTTPS (profil https du docker compose) ou depuis http://localhost.

Voir docs/03-firmware-et-flash.md, section « Flasher depuis le navigateur ».

1. Flasher le firmware

À faire une seule fois par écran (les mises à jour suivantes passent par l'OTA). Branchez l'écran en USB-C, interrupteur sur ON.

Aucun firmware avec image complète n'a été publié. Compilez-le avec docker compose run --rm firmware (voir la documentation).

Si l'écran n'apparaît pas dans la liste : changez de câble (certains câbles USB-C ne font que la charge), ou maintenez le bouton BOOT en branchant.
